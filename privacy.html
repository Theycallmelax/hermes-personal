Privacy Policy

Hermes Personal — last updated 7 October 2026

Hermes Personal is a private, single-user personal assistant used by one person on their own machine. This policy explains how it handles data from the owner’s Google Account.

1. What Google data is accessed

With the owner’s explicit consent, the application requests two read-only permissions:

  • https://www.googleapis.com/auth/gmail.readonly — to read the owner’s Gmail messages.
  • https://www.googleapis.com/auth/calendar.readonly — to read the owner’s Google Calendar events.

No other Google data is requested or accessed. The application cannot send, edit, delete, or otherwise modify any Gmail message or Calendar event.

2. How the data is used

The data is used solely to operate the assistant for its owner: summarising incoming messages, flagging items that need attention, and keeping track of the owner’s schedule and deadlines. The data is shown only to the owner.

3. Storage

An OAuth refresh token is stored locally on the owner’s own machine so the assistant can reconnect without the owner signing in each time. Message and calendar content is processed locally and is not copied to any third-party server.

4. Sharing

The data is never sold, rented, or shared with any third party. It is not used for advertising, profiling, or training machine-learning models.

5. Google API Services User Data Policy

This application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Data is retained only as long as needed to operate the assistant. The owner can revoke the application’s access at any time at myaccount.google.com/permissions, which immediately stops all access. On revocation, stored message and calendar content is deleted.

7. Changes

Any material change to this policy will be reflected on this page, with the “last updated” date above.
